02 · Govern

Unity Catalog decides.

Who can open what, which rows they see, and what a page is allowed to do.

Built in

Queries run as the viewer

Each query runs with the signed-in person’s own access, so Unity Catalog grants, row filters and column masks apply whatever the page does. Running a dataset as the app is a deliberate, per-dataset choice with a named audience.

auth: user (default) · auth: app

How it works: queries run as the viewer →
Built in

Access in four layers

Control who opens the portal, who sees each dashboard, who sees a sensitive part of a dashboard, and, underneath it all, what the data itself allows.

How it works: access in four layers →
Built in

Safe SQL by construction

Read-only queries only, from approved catalogs, with filter values passed as typed parameters. Every pull request checks the rules and every deploy test-runs each query before anything changes.

check.py · pytest · LIMIT 0

Built in

Pages can’t call out

The browser is told to load scripts and data only from the portal, so a dashboard page is blocked from loading code from, or sending data to, sites the portal hasn’t listed.

05 · Not included

What it doesn’t do.

Known gaps, taken from the project’s own limitations and decision records. Check these against how your reports are used before you plan a migration.

  • No scheduled emails, subscriptions or data alerts. Nothing is pushed to people; they open the portal.
  • No paginated reports, PDF or PowerPoint export. Tables export to CSV and Excel.
  • No drag-and-drop editor or write-back. Pages are HTML and JavaScript, written by a person or a coding agent.
  • Databricks only. It needs Databricks Apps, a SQL warehouse, and user authorization for apps switched on by a workspace admin.
  • Caches live in app memory. A restart, deploy or evening stop empties them, and they aren’t shared between app instances.
  • Rows are capped and arrive as text. 500,000 rows by default, so aggregate in SQL.
  • Not an automatic Power BI converter. Measures are rewritten as SQL and reconciled. Metric views and Genie Agents are reviewed and provisioned separately.
  • Ask Genie needs a Genie space you build. LakeBoard never creates or changes spaces.
  • No native mobile app or Teams embedding. Phones get the responsive browser layout.
